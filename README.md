1. Membuat Struktur HTML

Pada tahap ini, dibuat dokumen HTML dengan nama home.html sebagai halaman utama website. Struktur HTML terdiri dari header, nav, section, aside, dan footer.

Elemen tersebut digunakan untuk membagi halaman menjadi beberapa bagian agar struktur website lebih teratur dan mudah dikelola.






2. Membuat Header dan Navigasi

Bagian header digunakan untuk menampilkan judul website, yaitu "Layout Sederhana". Sementara itu, navigasi dibuat menggunakan elemen <nav> yang berisi tautan menuju halaman Home, Artikel, About, dan Kontak.

CSS digunakan untuk mengatur warna latar navigasi, warna teks, jarak antar menu, dan efek ketika menu disorot.

3. Membuat Hero Panel

Hero panel dibuat menggunakan elemen <section id="hero">. Bagian ini berisi judul "Hello World!", paragraf deskripsi, dan tombol "Learn more".

CSS digunakan untuk memberikan warna latar abu-abu, mengatur jarak dalam elemen, ukuran judul, dan ukuran teks agar tampilan lebih menarik.

Screenshot:




4. Mengatur Main Content dan Sidebar

Pada tahap ini, halaman dibagi menjadi dua kolom, yaitu main content dan sidebar. Main content digunakan untuk menampilkan isi utama website, sedangkan sidebar digunakan untuk menampilkan informasi tambahan.

Properti CSS float: left digunakan untuk menempatkan kedua bagian secara berdampingan. Properti width dan padding digunakan untuk mengatur lebar serta jarak dalam setiap bagian.

Screenshot:




5. Membuat Sidebar Widget

Sidebar dilengkapi dengan dua widget, yaitu Widget Header dan Widget Text. Widget Header berisi daftar tautan, sedangkan Widget Text berisi informasi berupa paragraf.

CSS digunakan untuk mengatur garis pembatas, warna judul widget, jarak teks, serta efek hover pada tautan.

Screenshot:




6. Membuat Artikel dan Gambar

Pada bagian main content, dibuat dua elemen artikel menggunakan <article class="entry">. Setiap artikel berisi judul, gambar, dan paragraf.

Properti CSS float: left digunakan untuk menempatkan gambar di sebelah kiri teks, sedangkan class right-img digunakan untuk menempatkan gambar artikel kedua di sebelah kanan.

Elemen <hr class="divider"> digunakan sebagai garis pemisah antarartikel.

Screenshot:




7. Membuat Tiga Box Konten

Tiga box konten dibuat menggunakan elemen <div class="box">. Setiap box berisi gambar, judul, deskripsi singkat, dan tombol View Detail.

CSS digunakan untuk mengatur lebar box, posisi konten, perataan teks, dan bentuk gambar menggunakan border-radius: 50%.

Screenshot:




8. Membuat Halaman About

Halaman about.html dibuat untuk menampilkan informasi mengenai profil, deskripsi diri, portfolio, dan keahlian. Halaman ini menggunakan struktur layout yang sama dengan halaman Home agar tampilan website tetap konsisten.

Navigasi juga disesuaikan dengan menandai menu About sebagai halaman aktif.

Screenshot:




9. Membuat Halaman Contact

Halaman kontak.html dibuat untuk menyediakan formulir kontak. Formulir terdiri dari kolom nama lengkap, email, subjek, dan pesan.

Elemen <form>, <input>, <textarea>, <label>, dan <button> digunakan untuk membangun formulir. CSS digunakan untuk mengatur ukuran kolom, jarak antarinput, garis tepi, dan warna ketika kolom dipilih.

Formulir ini masih berupa tampilan antarmuka dan belum terhubung ke database atau layanan pengiriman pesan.
